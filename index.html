GitHub를 활용하여 학생들과 함께할 수 있는 사회 형성평가 퀴즈를 만드는 방법

📌 GITHUB 퀴즈 만들기 - 한눈에 보기

🎯 무엇을 만들까?

GitHub를 이용하여 「즐거운 사회 형성평가」 형태의 퀴즈 웹페이지를 만든다.

🌏 어떤 퀴즈?

대한민국, 일본, 중국, 몽골, 필리핀의 수도를 맞히는 아시아 국가 수도 퀴즈를 만든다.

📝 문제 구성

각 국가마다 정답은 1개, 오답은 3개로 구성한다. 오답은 세계의 다른 수도들로 구성한다.

🌍 게임 디자인

배경에는 둥글고 귀여운 지구 캐릭터가 등장하여 퀴즈를 안내한다.

😊 정답일 때

학생이 문제를 맞히면 귀여운 지구 캐릭터가 방긋 웃는다.

😢 오답일 때

학생이 문제를 틀리면 귀여운 지구 캐릭터가 슬픈 표정을 짓는다.

🎉 3문제 이상 정답

최종 결과 화면에서 지구 캐릭터가 신나게 점프하는 모션을 보여준다.

💥 3문제 이상 오답

최종 결과 화면에서 지구 캐릭터가 폭발하는 모션을 보여준다.

📱 학생 활용

완성된 웹페이지를 공개하고 링크를 QR코드로 만들어 학생들이 스마트폰으로 접속할 수 있다.

🚀 GITHUB 제작 순서

STEP 01
GitHub 가입
GitHub에 가입한 후 로그인한다.
STEP 02
New 클릭
GitHub에서 New를 클릭한다.
STEP 03
프로그램 이름 입력
만들 프로그램의 이름을 입력한다.

예: capital-city-game
STEP 04
파일 만들기
creating a new file을 클릭한다.
STEP 05
HTML 코드 붙여넣기
ChatGPT가 작성해준 HTML 코드를 복사하여 붙여넣는다.
STEP 06
저장하기
작성한 HTML 파일을 저장한다.
STEP 07
Settings 클릭
GitHub 저장소에서 Settings를 클릭한다.
STEP 08
Pages 클릭
왼쪽 메뉴에서 Pages를 클릭한다.
STEP 09
Pages 설정
문서에 안내된 방식으로 Pages 설정을 변경한 뒤 Save를 클릭한다.
STEP 10
링크 확인
약 1분 정도 기다리면 웹페이지 링크가 생성된다.
STEP 11
QR코드 만들기
생성된 링크를 QR코드로 변환하여 학생들에게 공유한다.
STEP 12
내용 수정하기
Code → index.html → 연필 아이콘 을 이용하여 코드를 수정할 수 있다.
